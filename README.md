Sentiment Analysis Using NLP & Machine Learning

📌 Project Overview

This project is developed as part of the Horizon TechX AI & Data Science Internship – Task 6.

The project focuses on building a Sentiment Analysis system using Natural Language Processing (NLP) and Machine Learning techniques. The application analyzes textual input and predicts the sentiment expressed in the text.

The system is designed to provide a simple and interactive interface where users can enter text and receive a sentiment prediction.

---

🎯 Objectives

The main objectives of this project are to:

- Understand and implement Natural Language Processing techniques.
- Preprocess and clean textual data.
- Convert text into numerical features suitable for machine learning.
- Train and evaluate a sentiment classification model.
- Predict the sentiment of previously unseen text.
- Develop an interactive web interface for real-time sentiment prediction.
- Deploy the application using Streamlit.

🧹 Data Preprocessing

The text data is processed before being provided to the machine learning model.

Typical preprocessing steps include:

- Converting text to lowercase
- Removing unnecessary characters
- Cleaning unwanted spaces
- Removing irrelevant words
- Tokenization
- Preparing text for feature extraction

These steps help improve the quality and consistency of the input data.

---

🤖 Machine Learning

After preprocessing, the textual data is transformed into numerical features that can be understood by a machine learning algorithm.

The model is trained to classify text according to its sentiment.

Model performance can be evaluated using metrics such as:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

▶️ How to Run the Project Locally

1. Clone the repository

git clone https://github.com/pranaligunjal2007/horizontech-sentiment-analysis.git

2. Navigate to the project directory

cd horizontech-sentiment-analysis

3. Install the required dependencies

pip install -r requirements.txt

4. Run the Streamlit application

streamlit run app.py

The application will open in your browser.
